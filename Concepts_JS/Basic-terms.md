# Explanation of Async and Await

- **`async`**:  
  It schedules a task to run after a set time (e.g., 1 second), but it doesn’t stop other tasks from running. The code after async eg.(`setTimeout`) runs immediately without waiting.  

- **`await`**:  
  It pauses the execution of a function until a task is finished (e.g., waiting 1 second). The code after `await` does not run until the task is complete.
